# معیار از پیش ثبت‌شده برای مقایسهٔ مدل

**ثبت: ۱۸ نوامبر ۲۰۲۶، پیش از دریافت کامل و سنجش دادهٔ آزمون ۲۰۲۶.** دسترسی به فایل ایستگاه و سه روز نمونهٔ ERA5 بررسی شده، اما خطای مدل برای ۲۰۲۶ دیده نشده است. این سند تصمیم پژوهشی دربارهٔ Ridge فعلی را قفل می‌کند. نتیجهٔ ایستگاهی ۲۰۲۵ قبلاً دیده شده و فقط برای طراحی این آزمون به کار رفته است؛ سال ۲۰۲۵ آزمون نهاییِ این تصمیم نیست.

## داده و روش ثابت

- منبع ویژگی و برچسب آموزش: Open-Meteo ERA5، روز `Asia/Tehran`، پنج شهر و سه هدف `Mean_C`, `Min_C`, `Max_C`.
- مرجع آزمون: گزارش‌های ساعتی NOAA GHCNh همان پنج ایستگاه، با قانون کیفیت و تجمیع ثبت‌شده در [گزارش روز محلی](LOCAL_STATION_VALIDATION_FA.md). کمینه و بیشینه تقریب ساعتی‌اند.
- آموزش Ridge فعلی با `alpha=100` و همان ویژگی‌ها، بدون جست‌وجوی مدل یا تنظیم ابرپارامتر، روی نمونه‌های دارای تاریخ هدف حداکثر ۲۰۲۵-۱۲-۳۱. پیش‌پردازش فقط روی همان نمونه‌های آموزش برازش می‌شود.
- آزمون: تاریخ هدف ۲۰۲۶-۰۱-۰۱ تا ۲۰۲۶-۱۰-۳۱ و تاریخ صدور از ۲۰۲۶-۰۱-۰۸. آخرین دادهٔ ERA5 مجاز برای هر صدور، هفت روز پیش از آن است. برچسب‌های ۲۰۲۶ فقط پس از ساخت پیش‌بینی‌ها برای امتیازدهی استفاده می‌شوند. هیچ سطر ایستگاهی وارد آموزش نمی‌شود.
- مبناها: آخرین مقدار مجاز و آخرین مقدارِ همان روز هفته؛ هر سه روش روی ردیف‌های ایستگاهی یکسان سنجیده می‌شوند. بازهٔ آزمون ۲۰۲۶، آلفا، ویژگی‌ها، فیلتر پوشش و قواعد زیر بعد از دیدن خطا تغییر نمی‌کنند. اگر پوشش کم باشد، نتیجه «نامعین» است، نه قبول.

## دروازهٔ تصمیم پژوهشی

برای هر یک از سه هدف، Ridge فقط وقتی «بهبود نسبت به مبناها» شمرده می‌شود که روی جفت‌های آزمون ۲۰۲۶:

1. MAE تجمیعی دست‌کم **۱۰٪ کمتر** از مبنایی باشد که روی همان جفت‌ها MAE کمتری دارد.
2. درصد پیش‌بینی با خطای حداکثر **±۲°C** دست‌کم **۵ واحد درصد بیشتر** از مبنایی باشد که روی همان جفت‌ها درصد بالاتری دارد.
3. در هیچ شهر/هدف با دست‌کم **۱۰۰ پیش‌بینی جفت‌شده**، MAE مدل بیش از **۰٫۵°C** بدتر از بهترین مبنای همان شهر/هدف نباشد.

هر سه شرط باید برای هر سه هدف برقرار باشند تا Ridge برای پژوهش حفظ شود. اگر یکی رد شود، همین نسخه انتخاب نمی‌شود؛ نتیجه، تحلیل شکست و مبنای بهتر ثبت می‌شوند. این معیار اجازهٔ بهینه‌سازی دوباره بر اساس آزمون ۲۰۲۶ نمی‌دهد. داده‌های روزهای متوالی و افق‌های هم‌پوشان مستقل نیستند؛ معیار، توصیفی است و ادعای فاصلهٔ اطمینان یا احتمال موفقیت آینده ندارد.

این دروازه **مجوز انتشار محصول ۳۰روزه نیست**. برای آن باید دقت به تفکیک شهر، هدف و افق، پوشش مشاهده، آرشیو پیش‌بینی‌های واقعاً صادرشده، حق استفاده از داده و آستانهٔ مورد قبول کاربر جداگانه بررسی شوند. API بازتحلیل ERA5 ممکن است دادهٔ تاریخی را بازبینی کند؛ حتی آزمون سال بعد با دانلود امروز، آزمون واقعاً عملیاتی نیست.
