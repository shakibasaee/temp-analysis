# آزمون مدل روی بازهٔ تازه‌تر ایستگاهی

**ثبت: ۱۸ نوامبر ۲۰۲۶.** [معیار پذیرش](MODEL_ACCEPTANCE_POLICY_FA.md) در کامیت‌های `a008863` و `db883d3` **پیش از محاسبهٔ خطای ۲۰۲۶** ثبت شد. در این آزمون، Ridge موجود با `alpha=100` و دو مبنای قبلی بدون تغییر و بدون تنظیم روی دادهٔ آزمون اجرا شدند. وضعیت تصمیم: **نامعین**؛ دادهٔ کنترل‌کیفیت‌شدهٔ ایستگاهی برای هیچ‌یک از پنج شهر به حداقل پوشش نرسید.

## داده و هم‌ترازی

فایل [ERA5 سال ۲۰۲۶](../data/era5_2026_five_cities.metadata.json) از Open-Meteo برای ۲۰۲۶-۰۱-۰۱ تا ۲۰۲۶-۱۰-۳۱ با روز `Asia/Tehran` دریافت شد: ۱٬۵۲۰ ردیف، پنج شهر و سه دما، بدون مقدار گمشده. این فایل به دادهٔ ۲۰۲۰–۲۰۲۵ متصل می‌شود. نمونه‌های با تاریخ هدف تا ۲۰۲۵-۱۲-۳۱ برای آموزش و نمونه‌های هدف ۲۰۲۶-۰۱-۰۱ تا ۲۰۲۶-۱۰-۳۱ با تاریخ صدور از ۲۰۲۶-۰۱-۰۸ برای آزمون هستند. آخرین ویژگی مجازِ ERA5، هفت روز پیش از تاریخ صدور است. پیش‌پردازش فقط روی آموزش برازش شد. این بازآزمایی **بازنگرانه** است؛ نسخهٔ ERA5 دریافت‌شده امروز ممکن است با مقدارِ واقعاً در دسترسِ روز صدور یکسان نباشد.

فایل‌های سالانهٔ [NOAA GHCNh](https://www.ncei.noaa.gov/products/global-historical-climatology-network-hourly) برای پنج ایستگاه تا ۱۴ نوامبر ۲۰۲۶ رکورد خام دارند. طبق [کد کیفیت رسمی](https://www.ncei.noaa.gov/oa/global-historical-climatology-network/hourly/doc/ghcnh_DOCUMENTATION.pdf)، مقدار `1` برای منبع این ایستگاه‌ها «Good» است. قانون قفل‌شدهٔ آزمون، فقط همین کد را می‌پذیرد. پس از اواخر فوریه/اوایل مارس، بیشتر رکوردهای دما **کد کیفیت خالی** دارند؛ این سند آن‌ها را «دادهٔ نادرست» نمی‌نامد، اما بدون پرچم قابل‌تأیید به‌عنوان مشاهدهٔ معتبرِ آزمون وارد نمی‌کند. قانون پوشش روزانه همان حداقل ۱۸ ساعت و ۳ ساعت در هر بخش شش‌ساعته است. دادهٔ خام ایستگاهی در Git قرار نگرفت؛ [ممیزی ۲۰۲۶](GHCNH_2026_STATION_AUDIT.json) تعدادها و هش هر منبع را ثبت می‌کند.

| شهر | آخرین روز محلیِ پذیرفته‌شده | روز هدف یکتای جفت‌شده در آزمون | حداقل لازم برای تصمیم |
|---|---|---:|---:|
| بندرعباس | ۲۰۲۶-۰۲-۲۷ | ۵۰ | ۱۰۰ |
| مشهد | ۲۰۲۶-۰۳-۰۴ | ۵۴ | ۱۰۰ |
| رشت | ۲۰۲۶-۰۲-۲۲ | ۶ | ۱۰۰ |
| سنندج | ۲۰۲۶-۰۳-۰۴ | ۵۳ | ۱۰۰ |
| یزد | ۲۰۲۶-۰۳-۰۴ | ۵۵ | ۱۰۰ |

از پیش‌بینی‌های آزمون، **۴٬۷۹۴** ردیف با مشاهدهٔ معتبر هم‌پوشان شدند، اما فقط **۲۱۸ جفت یکتای شهر/روز هدف** هستند. تعداد زیاد ردیف‌ها ناشی از تاریخ‌های صدور و افق‌های هم‌پوشان است؛ جای پوشش زمانی را نمی‌گیرد.

## خطاهای مشاهده‌شده و تصمیم

اعداد زیر فقط بازهٔ کوتاه و عمدتاً زمستانیِ دارای ایستگاه معتبر را توصیف می‌کنند. MAE بر حسب °C و عدد دوم درصد خطای حداکثر ±۲°C است. کمینه/بیشینهٔ ایستگاه از گزارش‌های ساعتی ساخته شده‌اند و حد حقیقی پیوستهٔ روز نیستند.

| روش | میانگین: MAE / ±۲°C | کمینه: MAE / ±۲°C | بیشینه: MAE / ±۲°C |
|---|---:|---:|---:|
| ماندگاری | ۵٫۸۲۳۹ / ۲۳٫۵۷٪ | ۵٫۲۴۵۵ / ۲۷٫۱۲٪ | ۷٫۲۸۸۳ / ۱۷٫۱۷٪ |
| همان روز هفته | ۶٫۰۳۱۵ / ۲۰٫۵۹٪ | ۵٫۴۰۴۸ / ۲۶٫۵۷٪ | ۷٫۴۲۶۱ / ۱۶٫۶۷٪ |
| Ridge | ۳٫۹۴۸۲ / ۲۸٫۰۴٪ | ۳٫۴۲۳۵ / ۳۹٫۰۷٪ | ۵٫۱۸۹۶ / ۱۸٫۳۴٪ |

Ridge در MAE تجمیعی هر سه هدف از مبناها بهتر بود، اما افزایش درصد ±۲°C برای میانگین **۴٫۴۶ واحد درصد** و بیشینه **۱٫۱۷ واحد درصد** است؛ کمتر از شرط ۵ واحدی. مهم‌تر از آن، هیچ شهر ۱۰۰ روز یکتای لازم ندارد. طبق معیار از پیش ثبت‌شده، **هیچ مدل تازه‌ای انتخاب نمی‌شود و Ridge نه قبول و نه رد نهایی می‌شود**. عددهای این بازه را با میانگین تمام سال ۲۰۲۵ مقایسهٔ مستقیم نکنید. [گزارش ماشینی](LATER_STATION_EVALUATION.json) برش شهر، افق، فصل و وضعیت هر شرط را نگه می‌دارد.

## بازتولید و کار باز

از ریشهٔ مخزن با `requirements.txt` و اینترنت:

```bash
python -m scripts.fetch_ghcnh --year 2026 --dir artifacts
python -m scripts.build_era5_dataset --start 2026-01-01 --end 2026-10-31 --out data/era5_2026_five_cities.csv
python -m scripts.evaluate_later_station_holdout --base data/era5_five_cities.csv --extension data/era5_2026_five_cities.csv --station-dir artifacts --out docs/LATER_STATION_EVALUATION.json --audit-out docs/GHCNH_2026_STATION_AUDIT.json
python -m unittest tests.test_later_station_holdout -v
```

بازدریافت منبع ممکن است به‌علت بازبینی NOAA یا ERA5 هش و تعدادها را تغییر دهد؛ نسخهٔ ERA5 و فرادادهٔ آن در مخزن ثبت شده‌اند، ولی حق بازنشر فایل خام ایستگاه هنوز روشن نیست. گام بعدی، یافتن مرجع ایستگاهی با پرچم کیفیت و پوشش کافی در ماه‌های بعد، یا گرفتن توضیح رسمی دربارهٔ کدهای خالیِ ۲۰۲۶ است. معیار پذیرش را پس از دیدن این نتیجه تغییر نمی‌دهیم. برای ادعای مهارت عملیاتی، آرشیو پیش‌بینی‌های صادرشده در زمان واقعی نیز لازم است.
